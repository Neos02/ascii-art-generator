# ASCII Art Generator

Try it out [here](https://nickkennedy.dev/ascii-art-generator)!

## Simple website that accepts an input image and generates an ASCII representation of it

This project was made for fun to see how ASCII art can be generated from an image. The website accepts jpeg, png, and webp images and converts them to ASCII characters. The output size and quality of each image can be tuned through the `Kernel Size` field, where a smaller kernel size results in a larger output with greater quality.
